# Mos Zoo BOT — Викторина «Тотемное животное» Московского зоопарка

VK-бот сообщества, который проводит короткую викторину и определяет тотемное животное пользователя. После результата предлагает узнать о программе опеки.

## Возможности

- 7 вопросов с вариантами ответов (кнопки)
- Подсчёт баллов по 8 животным
- Отправка фото тотемного животного
- Кнопки «Узнать больше» / «Стать опекуном» / «Пройти ещё раз»
- Сохранение состояния пользователей в `states.json`
- Отзывы через `/feedback текст` → `feedbacks.json`
- Уведомления администратору о результатах и отзывах

## Требования

- Python 3.10+
- Сообщество ВКонтакте с включённым Long Poll
- Токен сообщества с правами: **Сообщения сообщества**, **Управление сообществом**
